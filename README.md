# CommunityHelper

**Motivation:** matching the right volunteer to the right need is still broken — small orgs can't afford tooling and volunteers can't find fitting opportunities.
**Goal:** a free, accessible platform where skills, community needs, and organizational resources meet.

Volunteer–organization matching platform (Angular + ASP.NET Core + Flutter).

## Run

- Frontend: `cd frontend; npm install; npm start` → http://localhost:4200
- Backend: `cd backend; dotnet restore; dotnet run --project src/CommunityHelper.API`
- Mobile: `cd mobile; flutter pub get; flutter run`
